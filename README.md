# AI Lab Enterprise — The AI Powered Enterprise

Static landing page (HTML + CSS + vanilla JS, no build step).

- `index.html` — markup and inline SVG icon sprite
- `assets/css/styles.css` — design tokens, layout, 3D effects, responsive rules
- `assets/js/main.js` — interactions: 3D hero scene, architecture 3D carousel, counters, scroll reveals, particle background

Run locally: open `index.html` in a browser, or `python3 -m http.server` and visit http://localhost:8000.
